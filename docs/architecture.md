# Архитектура Klavium

## Крейты

| Крейт | Роль |
|---|---|
| `klavium-core` | Чистая логика без Win32: карты раскладок, детекция и конверсия текста, словари и биграммы, статистика, обработка распознанной речи. Тестируется полностью изолированно. |
| `klavium-platform` | Системный слой Windows: клавиатурный хук (`WH_KEYBOARD_LL`), инъекция ввода (`SendInput`), переключение раскладок, single instance, автозапуск, оверлеи-карточки и тосты (layered-окна), FFI для Vosk. |
| `klavium-ui` | Интерфейс: трей-иконка и меню, окно настроек (egui/eframe). |
| `klavium-app` | Бинарник: конфигурация, журналирование, сервисы (статистика, звуки, мониторинг раскладки), голосовой конвейер, главный цикл. |

**Правило `unsafe`:** весь FFI и `unsafe`-код изолированы в `klavium-platform`; в остальных крейтах действует линт `unsafe_code = "forbid"`.

## Поток данных: исправление раскладки

```
Клавиатура ──► хук WH_KEYBOARD_LL (platform::hook)
     │
     ▼
буфер последнего слова (app::engine)
     │
     ▼
проверка по словарям и биграммам (core::detect)
     │
     ▼
решение: подсказка или автокоррекция
     │
     ├─► карточка «было → станет» у каретки (platform::overlay)
     └─► перепечатка слова с переключением раскладки (platform::inject)
```

## Поток данных: голосовой ввод

```
Микрофон ──► сегментация по тишине (app::voice::audio)
     │
     ▼
движок распознавания: Whisper (офлайн) / Vosk (офлайн) / Google (онлайн)
     │
     ▼
пунктуация, команды, заглавные буквы (core::voice)
     │
     ▼
инъекция текста в активное окно (platform::inject)
```

## Каталог данных

Настройки, статистика, журналы и модели хранятся в каталоге `data\` рядом с программой (портативная схема); каталог можно сменить в настройках.

## Тестирование

- `klavium-core` — модульные тесты и контрольный корпус (85 кейсов конвертации и коррекции, `tests/corpus.rs`).
- `cargo test --workspace` — весь набор; CI (GitHub Actions) прогоняет `fmt`, `clippy`, тесты и сборку.

## Сборка и релиз

```powershell
cargo build --workspace        # сборка
cargo test --workspace         # тесты
cargo clippy --workspace --all-targets -- -D warnings
pwsh tools\build_dist.ps1      # установщик NSIS + portable zip (dist\)
```
